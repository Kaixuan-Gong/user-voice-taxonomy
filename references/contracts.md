## 语义特征 JSONL

执行本 Skill 的 AI 直接阅读 `ai_feature_batches.jsonl`，逐条分析并写 `semantic_features.jsonl`。每行必须是：

```json
{"record_id":"1","key_points":["配送超时"],"problem_object":"配送履约","user_request":"尽快送达","cause":"骑手长时间未更新","emotion":"不满","severity":"中","evidence_spans":["等了两个小时还没送到"],"multi_intent":false,"issue_spans":[{"issue":"配送超时","evidence":"等了两个小时还没送到"}]}
```

硬约束：

- `evidence_spans` 和每个 `issue_spans[].evidence` 必须是原声中的连续原文片段；不能改写。
- `key_points` 使用具体问题表现，不使用“体验差”“服务问题”等泛词。
- 多意图时，每个可独立治理的问题点写一个 `issue_spans`；单意图也至少写一个。
- 不确定内容留空或标记“未知”，不要补造原因。

## 聚类摘要交接

运行 `cluster` 后读取 `cluster_summaries.json`、`threshold_diagnostics.json` 和代表原声。执行 AI 生成候选标签时必须：

1. 先按每个簇总结共同问题与边界，不以单条样本命名。
2. 将不稳定噪声簇保留为“未知问题候选”，不要硬塞进已有类别。
3. 生成一级→二级→三级标签；层级是“属于”关系，正交维度不要混入主问题树。
4. 同级名称具体、互斥；同义合并，混杂簇拆分。
5. 给每个标签写完整定义卡。

## 标签体系 JSON

```json
{
  "version":"v1",
  "business_context":"本地生活用户原声分析",
  "labels":[
    {
      "label_id":"L1_DELIVERY",
      "parent_id":null,
      "level":1,
      "name":"履约问题",
      "definition":"用户反馈订单从接单到完成过程中的时效或执行异常",
      "include":["配送超时","未送达"],
      "exclude":["商品本身破损"],
      "positive_examples":["等了两个小时还没送到"],
      "negative_examples":["收到的商品碎了"],
      "business_action":"路由履约治理并监控时效",
      "status":"active"
    }
  ]
}
```

标签树要求：

- `label_id` 全版本稳定；改名不换 ID。
- 一级 `parent_id=null`，二三级父节点必须存在且层级连续。
- 每个父节点默认不超过 20 个子标签；超过时优先重构层级。
- 每个叶子标签必须有定义、包含、不包含、正例、反例和业务动作。
- “其他”只作为临时兜底；无法覆盖的新问题进入拒识与复核队列。

## 金标训练 JSONL

只有人工确认后才能作为训练和最终测试依据：

```json
{"record_id":"1","text":"等了两个小时还没送到","label_ids":["L1_DELIVERY","L2_TIMEOUT","L3_SEVERE_DELAY"]}
```

训练集、校准集与测试集按 `record_id` 隔离，禁止同一原声的不同 issue 跨集合泄漏。

## 阈值口径

- 聚类相似度：默认自动测试 `0.62, 0.66, 0.70, 0.72, 0.74, 0.76, 0.78, 0.80`，综合轮廓系数、噪声率、最大簇占比选取；业务有明确口径时可手动覆盖。
- 标签重叠告警：同级标签定义向量相似度默认 `>=0.86`。
- Laya 接受阈值：Top1 概率默认 `>=0.50`，Top1-Top2 差值默认 `>=0.10`；未用金标校准前只能作为工程起点。
- 覆盖率治理：默认非一级标签超过 `25%` 进入拆分检查；低于 `0.5%` 且样本少于 20 进入合并/观察检查；未知超过 `10%` 重新聚类。

## 六张飞书子表

最终必须交付一张飞书电子表格，固定包含：

1. `运行说明`：数据口径、模型版本、标签版本、阈值、阈值敏感性、处理方法与限制。
2. `打标明细`：原声、证据、特征、三级标签路径、概率、状态、版本。
3. `标签体系`：完整定义卡与层级关系。
4. `标签分布`：数量、占比和治理建议。
5. `TOP问题`：聚类规模、高频问题点、代表原声。
6. `人工复核队列`：低置信、近似并列、未知或异常样本，预留人工标签和备注列。
